# Daniel — Portofolio Web
Website statis (HTML, CSS, JS), tanpa build step.

## Deploy ke Vercel lewat GitHub
1. Buat repo baru di GitHub, upload semua isi folder ini (index.html di root repo).
2. Di vercel.com klik Add New > Project, pilih repo tadi.
3. Framework Preset: Other. Build Command dan Output Directory dikosongkan. Klik Deploy.

## Edit cepat
- Teks dan link: index.html
- Warna: variabel di bagian atas style.css
- Kalimat animasi ketik: array `words` di script.js
